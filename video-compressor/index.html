Frequently asked questions

Is this tool free?

The NEXORA compressor is offered as a free browser-based tool. No account is required to open the compressor.

Will the output be exactly selected MB target?

Not necessarily. The selected size is a target estimate. Check the actual exported size after processing.

Does it work on every phone and browser?

No. Video decoding, MediaRecorder, audio capture and available memory differ by browser and device. Try a short sample first.

Does compression reduce quality?

It can. Smaller target sizes generally require stronger compression. Preview the output and choose a larger target if quality matters more than file size.
