How to Create a Strong Password

Use a longer password whenever possible and combine different character types. Avoid easily guessed information such as names, birthdays, phone numbers or common words.

Use Longer Passwords

Increasing password length generally makes random passwords harder to guess.

Use Different Character Types

Combining uppercase letters, lowercase letters, numbers and symbols increases the available character combinations.

Use Unique Passwords

Avoid reusing the same password across multiple important accounts.
